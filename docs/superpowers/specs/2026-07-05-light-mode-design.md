# Terra Nova — 전 페이지 라이트 모드 + 토글 (설계 스펙)

- 작성일: 2026-07-05
- 범위: 22개 정적 HTML 페이지 + mobile-app.css(폰 셸) 라이트 테마 + 상단 네비 토글
- 목표: 다크(기본, 브랜드) 유지 + 라이트 모드 선택·저장·시스템 존중. 첫인상 개선 후속.
- 제약: 결제 흐름 마크업 불변(카카오페이 심사 — 색 변수만 조정). 교재 미리보기 이미지 원본 유지.

---

## 1. 확정된 결정 (사용자 승인)

| 항목 | 결정 |
|---|---|
| 구현 방식 | **격리 방식** — 각 페이지 인라인 `<style>`에 `html.light{}` 색 오버라이드 추가. shared.css 설계 철학(페이지 격리) 준수. |
| 토글 위치 | 상단 `.site-nav` 우측, 구독신청 버튼 옆 ☀/🌙 아이콘. 네비 여백 살짝 확대. |
| 저장 | `localStorage['tn-theme']`(`'light'`/`'dark'`). 없으면 `prefers-color-scheme`. |
| FOUC | `<head>` 최상단 인라인 스크립트로 저장값 즉시 `html`에 적용(깜박임 0). |
| 모바일 | mobile-app.css에 `html.light` 대응 규칙 추가 → 폰 카드·탭바·입력창 라이트. |
| 히어로(우주) | **(b) 라이트에서도 밝게** — 배경 밝게 + 파티클 색을 어둡게/민트로 반전해 흰 배경에서 보이게. 완전 일관. |
| 라이트 액센트 | 형광 민트 #00FFA3 → **진한 민트 #00B37A**(흰 배경 WCAG 대비 확보). 브랜드감 유지. |

## 2. 공통화 전략 (22페이지 반복 최소화)

- **공용 파일 `theme-toggle.js` 신설** — (a) FOUC용 즉시적용은 `<head>` 인라인(파일로 못 뺌), (b) 토글 버튼 클릭→`html.light` 토글→localStorage 저장→아이콘 갱신 로직은 이 파일에 1곳. 전 페이지가 `<script src="theme-toggle.js" defer>` 한 줄로 로드.
- **토글 버튼 HTML**은 각 페이지 `.site-nav`에 삽입(정적 네비라 nav-auth.js 주입 불가). 동일 스니펫 복붙.
- **라이트 색 오버라이드**: 표준 팔레트 1세트를 페이지마다 `html.light{}`로 복붙. 페이지별 변수명 차이는 매핑표(§3)로 흡수.

## 3. 라이트 팔레트 (표준)

각 페이지가 쓰는 의미론적 변수만 재정의. 대표 매핑:

| 역할 | 다크 | 라이트 |
|---|---|---|
| `--bg` 배경 | #0A0A0A | #FFFFFF |
| `--bg2` 보조배경 | #0E0E0E | #F4F6F7 |
| `--txt` 본문 | #F0F0F0 | #16181C |
| `--dim` 흐린 텍스트 | rgba(240,240,240,.62) | rgba(20,22,28,.64) |
| `--dim2` 더 흐림 | rgba(240,240,240,.32) | rgba(20,22,28,.40) |
| `--line` 라인 | rgba(255,255,255,.08) | rgba(0,0,0,.10) |
| `--accent` 액센트 | #00FFA3 | #00B37A |
| `--accent2` 보조액센트 | #2DD4BF | #0E9E86 |
| `--card` 카드 | #1C1C1C / #12141B | #FFFFFF (+그림자) |

- 페이지별 변수명 alias(예: `--dark`, `--mint`, `--ink`, `--faint`)는 각 페이지 `:root`를 읽고 그에 맞춰 오버라이드.
- 카드/입력창은 다크에서 어두운 면 → 라이트에서 흰 카드 + 옅은 그림자/보더로 입체감 유지.

## 4. 히어로 라이트 처리 (index/landing)

- `.hero` 배경: 라이트에서 밝은 그라데이션(#F4F6F7→#FFFFFF)로.
- 스타필드 canvas(`#hero-warp`, `#bg-canvas`): 파티클 렌더 색을 라이트일 때 어두운 민트/회색으로 반전(JS에서 `html.light` 감지 → 파티클 color 분기). 캔버스 배경도 밝게.
- "TERRA NOVA" 대형 브랜드 텍스트: 라이트에서 진한 잉크색.
- 토글 전환 시 캔버스가 이미 그려진 상태면 색만 다음 프레임부터 반영(리로드 불필요, 약간의 지연 허용).

## 5. 범위·순서

1. **1단계 (검증 기준점)**: `theme-toggle.js` + FOUC 스니펫 + 토글 버튼 + 라이트 팔레트를 **index.html·landing.html**에 완성. 데스크톱/모바일 × 라이트/다크 4종 스크린샷 + 토글·FOUC·캔버스 색 검증.
2. **2단계**: 나머지 20개 페이지에 (토글 버튼 + FOUC 스니펫 + theme-toggle.js + 라이트 팔레트) 일괄 적용. 페이지별 라이트/다크 대조 스크린샷.
3. **3단계**: mobile-app.css 라이트 규칙 보강, 폰 뷰포트 전수 확인.

## 6. 안전장치

- **순수 추가**: 다크 값은 그대로. 라이트는 `html.light` 하위에서만 작동 → 오버라이드 블록 제거하면 원상복구.
- **결제 불변**: order/market_checkout/payment-complete 마크업·로직 미변경(색 변수만).
- **회귀 검증**: 각 페이지 다크 스크린샷을 적용 전후 비교(다크가 변하면 안 됨). JS 콘솔 에러 0 확인.
- **shared.css**: `--tn-*` fallback에도 라이트 대응 추가(페이지가 변수 정의 누락 시 안전망).

## 7. 비목표 (YAGNI)

- 페이지별 색 하드코딩을 `--tn-*`로 전면 리팩터링(방법 2)은 하지 않음 — 격리 철학 위반·회귀 위험.
- 교재 PDF/미리보기 이미지 자체의 라이트/다크 변형 없음.
- 자동 시간대별 전환(일몰 후 다크 등) 없음 — 수동 토글 + 시스템 존중까지만.
