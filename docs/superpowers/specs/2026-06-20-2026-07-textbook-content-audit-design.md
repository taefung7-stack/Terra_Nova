# 2026-07 고등 교재 본문 내용 정확성 전수 검수 — 설계

- **작성일:** 2026-06-20
- **작업 코드:** A (교재 검수). 표지(B)·업로드(C)·홍보(D)는 별도 사이클.
- **상태:** 설계 승인됨 → 구현 계획 대기

---

## 1. 배경 / 목적

2026-07 월간 구독 교재(고1 Saturn / 고2 Jupiter / 고3 Sun, 각 20지문 = **총 60지문**)는
본문 JSON·개별 PDF·풀북 PDF·삽화까지 **빌드는 완료**된 상태다. 그러나 판매(Storage 업로드) 전
**내용 정확성이 전수 검증되지 않았다.**

목적: 60지문 전부에 대해 **"판매를 막을 결함(blocker)이 있는가 + 그 근거"** 를 검증한
리포트를 산출한다. 검수 깊이는 **교육과정·수능 정렬까지** (자체 정합성 + 2022 개정 성취기준 +
Lexile/난이도 실측).

이 작업은 **진단까지만** 한다. 결함 수정은 리포트 확인 후 결함 양에 따라 별도 결정(YAGNI).

## 2. 검수 대상

- 경로: `textbook/content/passages/2026-07/`(고1), `2026-07-J/`(고2), `2026-07-Sun/`(고3)
- 각 지문 구성: `page1`(본문 body + 어휘 gloss/gloss_extra) / `page2` / `page3`(해설) /
  `translation_ko` / 문제·정답
- 보조 산출물: `textbook/dist/2026-07/<학년>/` 개별·풀북 PDF, `textbook/assets/illustrations/2026-07-*/` 삽화

## 3. 검수 기준 — 3층

| 층 | 검사 항목 | 방법 |
|----|----------|------|
| **L1 구조/기계** | overflow, placeholder 잔존, page3 ≤ 20, 본문 단어수(290–360 & ≥1400자), 따옴표 escape, vocab 중복, 본문↔page3↔translation_ko 3자 동기화 | 자동: `npm run validate` (tools/validate-content.mjs) + 보조 |
| **L2 교육과정/난이도** | 2022 개정 성취기준 코드 타당성(NCIC), Lexile 라벨↔실측 정합, 학년 **내** 난이도 순서 | 자동: `tools/lexile-audit.py` + 에이전트 판단 |
| **L3 내용 질** | 영문 자연스러움·문법·CEFR 적합, 해설 논리·본문 근거 일치, 번역 정확성·누락, 정답 타당성·오답 변별 | **멀티에이전트 병렬** (지문당 4관점 → 적대검증) |

**정답 기준:** 외부 정답지 없음 → 자체 정합성 + 교육과정 정렬. L3 정답 검수는
"정답이 본문 근거로 타당한가"를 **적대적으로(refute 우선)** 검증한다.

**기존 도구/메모리 참조:**
- `tools/validate-content.mjs`, `tools/lexile-audit.py`(+ `lexile-audit-result.json`), `tools/mark-verified.mjs`
- 알려진 의심 지문(메모리): 고1 #17~20 난이도 역전, 고2 전반 Lexile 과대표기 의심,
  고1 성취기준 코드 13개 web추정(NCIC 원문 대조 미완)

## 4. 멀티에이전트 검수 구조 (L3)

파이프라인 — 60지문을 **독립적으로** 흘린다(지문 간 배리어 없음):

```
[L1+L2 자동 사전검사] → [L3 4관점 병렬] → [적대검증(의심건만)] → [지문별 종합 판정]
```

**L3 — 지문당 4관점 에이전트 병렬:**

| 관점 | 보는 것 |
|------|---------|
| 🔤 언어 | 영문 문법·자연스러움·어색 표현·CEFR 수준 적합성 |
| 📖 해설 | page3 해설 논리, 본문 근거 일치, 비약·오류 |
| 🇰🇷 번역 | translation_ko 정확성·누락·오역 |
| ✅ 문제·정답 | 정답 타당성, 오답 변별력, 함정 적절성 |

- 각 관점은 **구조화 출력(JSON 스키마)** 으로 findings 반환(파일·위치·심각도·근거).
- **적대검증:** "결함 있음" 표시 건만 독립 스켑틱이 **반박 우선**으로 재검. 다수 반박 시 false positive 폐기.
- **종합 판정:** confirmed findings를 심각도 **차단(blocker)/권고/경미** 로 분류.

**규모:** 60 × 4 = 240 검수 에이전트 + 적대검증(의심건만). 동시성은 워크플로 자동 제한(min 16).
토큰 사용 큼 → **Workflow 오케스트레이션**으로 실행(사용자 명시 동의 확보됨).
