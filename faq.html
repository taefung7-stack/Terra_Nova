구독 · 결제
구독은 어떻게 신청하나요? +

구독 신청 방법은 두 가지입니다.

  • 웹사이트 '구독 신청' 페이지에서 플랜과 레벨을 선택 후 신청
  • 카카오톡 채널 '테라노바 영어'로 문의 후 직접 신청
진행 중인 프로모션이 있는 경우 구독 신청 화면에서 쿠폰 코드를 입력해 적용할 수 있습니다.
결제는 어떻게 이루어지나요? +

월간 구독은 등록한 결제수단으로 매월 자동 결제됩니다. 결제 수단은 PG사 심사가 완료되는 대로 순차적으로 활성화되며, 카카오페이·NICE 간편결제·KG이니시스 카드를 지원할 예정입니다. 결제 실패 시 등록 이메일로 안내됩니다. 자세한 결제 안내는 이용약관·환불정책을 확인해주세요.

3가지 플랜의 차이가 무엇인가요? +

⚠️ 현재 LIGHT 플랜만 정식 운영 중입니다. STANDARD / PREMIUM 은 실물 배송 파트너 계약 완료 후 순차 오픈됩니다.

  • LIGHT (11,900원/월 · 연간 119,000원) ✅ 정식 운영 — PDF 교재 매월 발행. 태블릿/프린트로 학습. 레벨 변경 무료. 연간 결제 시 2개월 무료.
  • STANDARD (24,900원/월, 준비중) — LIGHT + 매월 실물 책 배송 + 단어장 + 모의고사. 출시 시 별도 공지.
  • PREMIUM (58,900원/월, 준비중) — STANDARD + 해설 영상 + 학습 코칭. 출시 시 별도 공지.
플랜을 변경할 수 있나요? +

현재는 LIGHT 플랜만 정식 운영 중이라 플랜 변경은 제공하지 않습니다. STANDARD/PREMIUM 출시 후 마이페이지에서 변경 신청할 수 있으며, 변경은 다음 결제일부터 적용됩니다.

배송
실물 교재는 언제 배송되나요? +

⚠️ 현재 실물 배송 플랜(STANDARD/PREMIUM)은 준비중입니다. LIGHT 플랜은 PDF 교재로 매월 발행되어 등록 이메일로 발송됩니다. 실물 배송은 STANDARD/PREMIUM 출시 시 매월 1~5일 일괄 발송 예정입니다.

배송비가 있나요? +

현재 정식 운영 중인 LIGHT 플랜은 PDF 발송이라 배송비가 없습니다. STANDARD/PREMIUM 출시 시 본토 무료, 제주·도서산간 추가 배송비(3,000원) 예정입니다.

배송 주소를 변경하고 싶습니다. +

마이페이지 → 배송 관리에서 주소를 변경하실 수 있습니다. 발송 전(매월 말일까지) 변경하셔야 당월에 적용됩니다. 이미 발송된 경우 변경이 불가능합니다.

교재를 받지 못했거나 파손된 경우 어떻게 하나요? +

현재 LIGHT 플랜은 PDF 발송 상품이라 실물 교재 배송이 없습니다. STANDARD/PREMIUM 출시 후 실물 교재가 누락·파손된 경우 사진과 함께 고객센터로 문의 주시면 확인 후 재발송 또는 교환 처리합니다.

레벨 · 교재
어느 레벨을 선택해야 할지 모르겠습니다. +

레벨 테스트 페이지에서 3분 만에 진단받을 수 있습니다. 학년과 현재 영어 수준을 입력하면 최적의 레벨을 추천해드립니다.

→ 레벨 테스트 받기
레벨을 중간에 변경할 수 있나요? +

네, 가능합니다. 마이페이지에서 레벨 변경을 신청하시면 다음 달 PDF 발행분부터 새 레벨 교재가 적용됩니다. 레벨 변경에 따른 추가 비용은 없습니다.

교과 연계 학습이란 무엇인가요? +

Terra Nova의 모든 영어 지문은 실제 학교 교과서 단원과 직결됩니다. 예를 들어 중2 과학 '전기와 자기' 단원을 배울 때, 같은 주제의 영어 지문을 읽으며 영어와 과학을 동시에 학습합니다.

  • 수학·과학·사회·국어·기술 교과서 단원과 연계
  • 체계적 커리큘럼으로 주 5일 학습
  • 영어 점수 + 전과목 배경지식 동시 향상
PDF는 어디서 다운로드하나요? +

결제 완료 후 마이페이지 → 학습 자료에서 매월 PDF를 다운로드하실 수 있습니다. 발행일(매월 1일)에 자동으로 업로드되며, 등록 이메일로도 안내됩니다.

환불 · 해지
구독을 해지하고 싶습니다. +

마이페이지 → 구독 관리 → '구독 해지' 버튼을 클릭하시면 됩니다. 해지 신청 시 당월 만료까지 서비스를 계속 이용하실 수 있으며, 다음 달부터 결제되지 않습니다.

해지 후 재구독 시에도 당시 진행 중인 프로모션·쿠폰 조건에 따릅니다.
환불 정책이 어떻게 되나요? +

전자상거래법 제17조에 따라 콘텐츠 이용 여부 기준으로 정합니다. 자세한 내용은 환불·교환 정책 전문을 확인해주세요.

  • LIGHT (PDF) — 결제 후 7일 이내 + 콘텐츠 미열람: 전액 환불
  • LIGHT (PDF) — 콘텐츠 다운로드/열람 후: 전자상거래법 제17조 제2항 5호에 따라 환불 불가
  • 월간 구독 — 결제일+7일 + 당월 콘텐츠 미수령: 100% 환불, 이후엔 자동 해지로 처리
  • 연간 구독 — 결제일+7일 + 미이용: 전액 환불 / 이용 시작 후엔 사용 월수 + 위약금 10% 차감 후 잔액 환불
  • STANDARD/PREMIUM 실물 (출시 후) — 수령+7일 미개봉: 전액 환불, 개봉/필기 시 환불 불가
실수로 잘못된 레벨을 선택했습니다. +

마이페이지 → 레벨 변경 신청으로 매월 1회 무료 변경 가능합니다. 다음 결제일부터 새 레벨로 발송됩니다.
