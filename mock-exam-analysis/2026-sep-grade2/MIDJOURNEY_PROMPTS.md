# 2026-09 고2 미드저니 삽화 프롬프트

각 지문 1장씩, `assets/illust-{N}.png` 로 저장하면 재빌드 시 자동 반영됩니다.

**규칙** — `--ar 16:5 --v 8.1` 고정, 밝은 vivid 톤(다크 키워드 금지),
부정 표현은 문장 안에 쓰지 말고 반드시 `--no` 파라미터로만 (인라인 "NO xxx"는
오히려 그 물체를 불러옴). 글자 차단 `--no text,letters,words,watermark,signature` 포함.

삽화가 없어도 빌드는 정상 동작하며, PNG를 넣은 뒤 `npm run build:sep2` 재실행하면 반영됩니다.
